# CSP Unit 9 – Create PT Prep: Vocabulary & Concepts

## How to read this

Each lesson lists only what's new: formal vocabulary and the concepts students should walk away with. Timing, prep, links, teaching tips, and teacher dialogue are cut.

- **Vocabulary** is copied word for word from the lesson's formal vocabulary box. Lessons without a box say "No formal vocabulary" and get concepts only.
- **Good to know** terms are defined in passing in the lesson but aren't in a formal vocabulary box. Their basic definitions are my own wording.
- **Key concepts** are condensed from the lesson's overview, objectives, presenter notes, discussion goals, and Check for Understanding.

*This unit is built around the AP Create Performance Task. None of its lessons have formal vocabulary.*

## Lesson 1: Create PT Deep Dive

**Vocabulary:** No formal vocabulary.

**Good to know** (not in the formal vocabulary box)

| Term | Basic definition |
| --- | --- |
| Create Performance Task (Create PT) | The AP CSP project where students build their own program and then answer written prompts about it |
| Personalized Project Reference (PPR) | Snippets of a student's own code, submitted with the Create PT and used when answering the written-response questions |

**Key concepts**

- The Create PT is a self-directed programming project plus responses to prompts about the program and the process.
- Students submit a PDF of their program code and a Personalized Project Reference with code snippets from their program. Lesson 3 also lists a program video.
- Students learn the scoring guidelines and practice applying them to sample Create PT components, using the Create PT Survival Guide.

## Lesson 2: Create PT Make a Plan

**Vocabulary:** No formal vocabulary.

**Key concepts**

- The written responses are the most important part of the Create PT.
- A small or even incomplete project is fine as long as it has a working feature to show.
- Narrow ideas down before starting. Many projects have sub-parts that could each stand alone as a PT. Pick one with a clear opportunity to use a list and a function.
- Don't spend much time in Design Mode or on how the app looks until the end.
- The Create PT is about showing what you already know how to do, not building something huge.
- A strong function to highlight includes a parameter, a loop, and an if-statement.
- Students finish by making a plan and timeline for completing the task.

## Lesson 3: Create PT Complete the Task (9 hrs)

**Vocabulary:** No formal vocabulary.

**Key concepts**

- The Create PT requires at least 9 hours of class time.
- Students may collaborate with a partner on the program, but written responses must be done individually.
- Teachers can advise on the process but can't evaluate or influence students' work or ideas.
- If students modify an existing project, its purpose must also be new or modified (for example, "adding a login feature to a game I made previously").
- Submission is through the AP Digital Portfolio: program code, program video, and Personalized Project Reference. Save and submit early, since the site can go down near deadlines.

## Lesson 4: Create PT Written Response Mock Exam

**Vocabulary:** No formal vocabulary.

**Key concepts**

- Over two days, students take a mock version of the written-response portion of the exam, which has four prompts.
- Day 1 covers the exam format, test-taking and annotation strategies, and responses to the "Program Design, Function, and Purpose" and "Algorithm Development" prompts, using completed Personalized Project References.
- Day 2 starts with a modeled annotation of a sample question, then students answer the remaining prompts and reflect with partners.
- Rushing through questions in limited time leads to shallow answers, so pace yourself and use strategies.
- Students reflect on Glows (what went well), Grows (what to improve), and areas of confusion.
